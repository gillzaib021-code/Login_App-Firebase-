🔐 Login & Signup App (Flutter + Firebase)

This is a Flutter application that implements user authentication using Firebase. The app allows users to sign up, log in, and store their personal information (name, email, password) in Firestore. It also includes a profile screen to display user data.

🚀 Features
🔐 User Signup with Firebase Authentication
🔑 User Login with email & password
☁️ Store user data in Firestore (Name, Email, Password)
👤 Profile Screen to display user information
🔄 Real-time Firebase integration
⚠️ Error handling for authentication
🛠️ Technologies Used
Flutter (UI Toolkit)
Dart (Programming Language)
Firebase Authentication
Cloud Firestore
⚙️ App Workflow

Users can create an account using their name, email, and password. After successful signup, data is stored in Firebase Firestore. Users can then log in and view their profile screen where their stored information is displayed.

📂 Project Structure
models/ → User model
services/ → Firebase authentication logic
screens/ → Login, Signup, Profile screens
widgets/ → Reusable UI components
main.dart → App entry point
